# Mart Layer

## Purpose
Publish stable, analysis-ready data for downstream consumers.

## Expected Characteristics
- Clearly documented grain.
- Business-friendly names.
- Validated uniqueness.
- Measures aligned for analysis.
- Reusable derived metrics.
- No repeated source-specific cleaning downstream.

## Provisional V1 Grain
One row per reporting period for the national U.S. housing market. This will be finalized after source frequencies are confirmed.

Initial consumer: Python/pandas in VS Code. Future consumers may include Power BI and forecasting models.
